## Selected Academic Projects

### 01. SynTafsir — Malay Syntactic Ambiguity Detection System

An individual final-year project focused on identifying syntactic ambiguity involving prepositional phrases in Malay sentences.

The system combines AI analysis with linguistic rules to identify and interpret potential ambiguities.

**Technologies:** Python, Streamlit, Ollama, Qwen2.5:3b, JSON, Regular Expressions.

### 02. ReSpace — Research Management System

A web-based research management system developed to manage research-related information.

Implemented backend CRUD operations and integrated a PostgreSQL database to support research data management.

**Technologies:** Java, Spring Boot, PostgreSQL, Docker, Git, GitHub.

### 03. UUM Food Delivery Application

A UI/UX design project developed for the Universiti Utara Malaysia community.

Designed application interfaces for food browsing, menu selection, online ordering, and nutritional information.

**Tool:** Figma.

### 04. Agoda Accommodation Review Analysis

A research-based data collection and analysis project involving online accommodation reviews in Peninsular Malaysia.

Used web scraping tools to collect and organise accommodation review information.

**Tools:** Instant Data Scraper, Apify.
