## Featured Projects

- **SynTafsir** — An individual project focused on detecting syntactic ambiguity involving prepositional phrases in Malay sentences. Built with Python, Streamlit, Ollama and Qwen2.5:3b.
- **ReSpace** — A research management web application involving backend CRUD operations and PostgreSQL integration. Built with Java, Spring Boot, PostgreSQL and Docker.
- **UUM Food Delivery App** — A UI/UX design project for the UUM community, designed using Figma.
- **Agoda Review Analysis** — A research data collection project using Instant Data Scraper and Apify.
